## 問題的核心

麻布記帳能自動同步你的銀行餘額和交易紀錄，這個功能很方便，但「讓一個 App 讀取我的銀行帳戶」這件事本身就讓很多人不舒服。

這篇要做的是說清楚麻布記帳的同步實際怎麼運作，哪些風險是真實的，哪些是因為不了解機制而過度擔心的。

---

## Open Banking 是什麼

「[開放銀行（Open Banking）](https://en.wikipedia.org/wiki/Open_banking)」是[金管會](https://www.fsc.gov.tw/)推動的制度，讓第三方服務可以在用戶授權下，透過標準化的 API 介面存取銀行的帳戶資訊。這個 API 機制底層通常採用 [OAuth 2.0 授權框架](https://datatracker.ietf.org/doc/html/rfc6749)（由 IETF 制定的開放標準），確保使用者不需把銀行密碼交給第三方 App。

關鍵在「授權」和「API 介面」這兩個詞。

標準的開放銀行授權流程是：進入銀行自己的授權頁面（不是第三方的頁面）→ 在銀行端登入 → 確認授權第三方讀取哪些資料 → 完成。第三方拿到的是一個有時間限制的 API 存取憑證，只能讀取你授權的資料，不經手你的網銀密碼。

但麻布記帳目前主要不是走這條路。官方把同步方式分成「授權同步」（開放銀行 API）和「代理同步」兩種，[2026 年 3 月更新的官方說明](https://blog.moneybook.com.tw/?p=1105)仍寫它主要使用代理同步：你在麻布 App 裡輸入網路銀行的身分證字號、使用者名稱和密碼，由它代你登入銀行的網頁版、把帳務資料抓回來（[官方同步方式說明](https://blog.moneybook.com.tw/?p=1012)）。所以對大多數銀行來說，麻布記帳是拿得到你的網銀帳密的。

---

## 這個機制的安全性

**不能轉帳**：官方說明麻布記帳無法進行任何交易，因為它拿不到刷卡時要填的信用卡有效期限、CVV 碼，也拿不到網銀交易需要的 OTP 簡訊驗證碼。所以就算麻布記帳的系統被入侵，攻擊者也無法透過這個管道轉走你的錢。

**資料加密存放**：官方說明資料以 AES-256 加密技術存放在 Google Cloud Platform 的虛擬私人雲端（VPC），只有指定 IP 可以進入。但這是「保管得好」，不是「拿不到」——代理同步的前提就是你把網銀帳密交給它。

**要切斷就改密碼**：代理同步用的是你的網銀密碼，不是一張可以單獨撤銷的 API 授權。想徹底切斷，最確實的做法是到網銀改密碼，麻布手上那組舊密碼失效，代理登入就進不去了。

**有第三方認證與開放銀行資歷**：麻布記帳是國內首家與多家銀行介接開放銀行第一階段「公開資料查詢」API（外幣匯率、存款利率這類非客戶資料）的業者、金管會指導的金融科技創新園區成員，並持有 ISO/IEC 27701 與 ISO/IEC 27001 認證。但要分清楚：認證證明的是它的資安管理流程，不代表它對你的銀行走的是開放銀行 API 授權。

---

## 真實存在的風險

說完有保護的地方，也要說真實的風險。

**麻布記帳本身的資安**：你的帳戶資料（餘額、交易紀錄）存在麻布的伺服器上，代理同步用的網銀帳密也經過麻布這一手。如果麻布的系統被入侵，這些資料可能外洩。這是你把財務資料和帳密交給第三方業者本身的風險。

**資料收集範圍**：你需要確認麻布記帳的隱私政策，了解它收集哪些資料、如何使用。2026 年 4 月起轉為付費制的同時，它的商業模式已從廣告 / 資料模式轉向直接訂閱收費，這在一定程度上降低了依賴資料變現的誘因。

**服務中斷風險**：如果麻布記帳停止服務，你的帳戶連結會失效，過去的交易記錄如果沒有匯出備份就可能遺失。

## 和「直接給帳密」的差別

把網路銀行帳號密碼直接交給 App、由它模擬登入去抓交易紀錄，這叫「螢幕擷取（screen scraping）」，不是 Open Banking。麻布的「代理同步」就屬於這一類：官方說明它代理同步的是金融機構電腦版網頁的資訊。

這種方式的風險比 Open Banking API 高——業者拿到的是你真正的網銀密碼，而不是只能讀資料、可以單獨撤銷的憑證。至於合不合法，麻布引述金管會的解釋：開放銀行合作範圍內禁止業者用消費者帳密存取，合作範圍外則可以由消費者授權使用登入資訊。

所以對多數銀行，麻布記帳走的是代理登入，不是 Open Banking API。這是評估它安不安全時最需要先分清楚的一點。

## 我的評估

麻布記帳目前主要靠代理同步，風險集中在「帳密和財務資料交給第三方保管」這一層，而不是「App 直接把錢轉走」的直接風險。

如果你的顧慮是「自動同步會讓別人轉走我的錢」，這個風險很低：麻布本身不能轉帳，網銀的非約定轉帳也還要 OTP 簡訊驗證碼。但帳密一旦外洩，別人就能登入你的網銀看資料；而且官方說明開啟二階段驗證會導致無法同步（[官方同步說明](https://blog.moneybook.com.tw/?page_id=4360)），等於要同步就得關掉這層登入保護，這點要算進去。降低風險的做法是盯住登入紀錄：官方說明麻布代你登入時，你會收到銀行端寄出的登入通知；你也可以在麻布 App 首頁上方的小鈴鐺進入「通知中心」、點右上角「紀錄」，查每次代為登入的機構與時間（[官方說明](https://blog.moneybook.com.tw/?p=1012)）。看到對不上的登入，就去網銀改密碼。

如果你的顧慮是「我不想讓第三方業者知道我的財務狀況」，這個顧慮是合理的，也不需要特別說服自己用這個功能——手動記帳的 App 同樣可以達到記帳的目的，只是需要自己輸入每一筆。[MOZE](https://moze.app/) 是 iOS 上口碑最好的手動記帳選項，完全不需要連結銀行帳戶，詳細功能與付費版評估見[MOZE 記帳 App 評測](/finance-tools/moze-review/)。

## 結論

麻布記帳的自動同步沒有轉帳風險，但它目前主要走代理同步，你的網銀帳密會交到它手上。風險在於把帳密和財務資料交給第三方業者保管這件事本身，這是一個你能接受或不能接受的選擇，不是非黑即白的問題。

對隱私要求不高、在意自動化便利的人，麻布記帳的同步功能是值得用的。對個人財務資料的流向很在意的人，手動記帳是更符合你需求的選擇。三款主流記帳 App 的功能與費用完整比較，見[記帳 App 哪個最適合懶人？](/finance-tools/budget-app-compare/)。
